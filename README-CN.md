# 仁王1 精防 MOD —— 工程说明

给《仁王1 完全版》（`nioh.exe` 1.24.8）加的**精准防御（精防）**MOD：在被击中的一瞬间按下防御，
就能触发精防并拿到收益。英文版见 [`README.md`](README.md)。

> **给玩家看的说明书**在 `mod/README_CN.md`、`mod/README_EN.md`、
> `QUICKSTART.md`、`验收测试说明.md`（实机验收清单），这些是**随包分发**的。
> 本文件是**工程/开发**说明。

---

## 这个 MOD 做什么

| 功能 | 本包状态 | 说明 |
| --- | --- | --- |
| 精防判定 | 开 | 格挡落在"防御键**按下沿** + `WindowMs`(250ms) 窗口"内 |
| 格挡耗精减免 | 开 | `KiDamageReductionPercent=100` |
| 回精 | 开 | `KiRecoveryMode=3`（回复最大精力的 1/6） |
| 对敌削精 / HP | 关 | `EnemyKiDamage` / `EnemyHpDamage`，带范围闸门，绝不猜目标 |
| 精防回血 | **开** | 默认回最大 HP 的 3%，也可用固定值 |
| **防御取消攻击动作** | **开** | **单按**防御键就取消当前动作；防御+X/Y/A（武技输入）保留给引擎 |
| 限时增益（移速/减伤/霸体） | **关，已停用** | 已按引擎自带状态对象实现，但按决定停用（见 `CHANGELOG.md` 2.0e）|
| 精防音效 | 开 | XAudio2，由独立线程播放 |

## 为什么这么实现

* **磁盘上的 `.text` 是加密的**（SteamStub 加密，与运行镜像只有约 0.39% 相同），
  所以全部逆向都在**运行时内存镜像**上做：用 `ReadProcessMemory` 导出并按 RVA 恒等映射重建
  （`tools/dump_module.py` → `_work/nioh1.mem.exe`）。
* **不修改游戏代码一个字节**：在少数锚点上装 x64 **硬件执行断点（DR0–DR3）**，
  在**向量化异常处理器（VEH）**里改写保存的线程上下文。
* 每个依赖的地址都在加载时**按字节校验**；不匹配就**拒绝安装**或降级，
  而不是往"新版本里可能已经变成别的东西"的地址上写（`tools/test_anchors.py`）。
* 需要触碰引擎自身系统的收益（限时增益）**绝不在异常处理器里调用**：处理器只启动计时器，
  真正的调用由看门狗线程执行。这条路上确实撞出过一次崩溃，过程记在
  `RE_NOTES.md` §4.52.2 / §4.54。

## 构建与验证

```powershell
.\build.ps1              # 编译、跑九项检查、生成 dist\
.\build.ps1 -Install     # 额外复制到游戏 mods\ 目录（必须先退出游戏）
build.cmd                # 双击等价
```

九项检查包括：锚点字节对账、**200 条**纯逻辑断言、"测试算术 == 发货算术"（比较测试程序与
发货 DLL 的指纹）、INI 默认值与编译默认值一致、文档标记/配置键、文档文件可达性、
每条日志都有上限、导出表。**任何一项不过就中止，且不产出包。**

> `build.ps1` 必须保持 **UTF-8 带 BOM**：Windows PowerShell 5.1 对无 BOM 的 `.ps1`
> 按 ANSI 解码，中文会乱码并破坏引号配对。脚本每次运行都会自检编码。

`tools/verify_buffs.ps1` 是"一条命令做实机实验"的脚本（装包 → 临时开功能 → 启动游戏 →
盯日志与崩溃转储 → 还原 INI）。

## 已知环境注意点

* 安装时**游戏必须已退出**（运行中 DLL 被占用）。
* DLL 哈希与**输出绝对路径**有关（Zig/lld 的 build id），换目录重建哈希本就不同；
  `SHA256SUMS.txt` 校验的是**这一份包**，不是"重构建应得此值"（`RE_NOTES.md` §4.49）。
* 被保护/残留的 `nioh.exe` 在**非提权**环境下结束不掉，会顶掉新实例 ——
  请用**管理员权限**的任务管理器结束，或重启一次。
